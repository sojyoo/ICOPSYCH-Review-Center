# Chapter 4: Results and Discussion
## Section 1: Presentation of Data and Exploratory Data Analysis

### 4.1 Presentation of Data

This section presents a comprehensive analysis of the datasets used to train and evaluate the adaptive review planning system for Psychometrician Licensure Examination preparation. The system integrates multiple data sources to provide personalized study recommendations and risk assessment for students at EARIST.

**Important Distinction**: This study employs a two-phase approach:
1. **Training Phase**: Previous cohorts' (BSP4A/BSP4B) performance data was used to train the machine learning model
2. **Deployment Phase**: Current cohort students (survey respondents) will receive personalized recommendations when they use the system

The primary datasets include:
- **Student Performance Data (Training)**: 154 unique student records from previous cohorts (BSP4A/BSP4B) with comprehensive academic performance metrics across four psychology subjects - **used to train the model**. Each student is identified by unique email address, derived from grouping Excel test files by student identifier.
- **Survey Response Data (Target Users)**: 44 responses from current 4th-year psychology students capturing study habits, motivations, and challenges - **represents future system users**
- **Recommendation Data (Examples)**: 564 subject-level recommendations and 329 topic-level recommendations generated by the system - **demonstrates model capabilities on training data**
- **Raw Assessment Files (Training)**: 11 pre-test and 18 post-test Excel files containing individual question responses from previous cohorts - **used for model training**

### 4.6 Data Quality and Preprocessing

#### 4.6.1 Missing Value Analysis

The Student Features dataset contains 2.3% missing values, primarily in study pattern features that were not consistently collected across all students. The Survey Data shows 8.7% missing values, mostly in optional GWA (General Weighted Average) fields that students were not required to complete. Missing values were imputed using median for numerical features and mode for categorical features, ensuring that the absence of data did not exclude students from analysis or model training.

#### 4.6.2 Outlier Detection

Five students were identified with scores greater than 2.5 standard deviations from the mean, representing extreme performance cases. Additionally, eight improvement cases showed outliers with improvements greater than 10 points (positive) or less than -10 points (negative). These outliers were retained in the dataset as they represent genuine performance variations requiring personalized attention rather than data errors. The system's ability to handle these extreme cases ensures that students with unusual performance patterns receive appropriate recommendations.

#### 4.6.3 Feature Engineering Summary

Several derived features were created to enhance the predictive power of the model. The Improvement Rate was calculated as the relative change between post-test and pre-test scores, normalized by the pre-test score. Score Consistency was measured using the coefficient of variation across multiple test attempts, capturing performance stability over time. Study Habit Composite Scores were created by normalizing Likert scale responses (originally 1-4) to a 0-1 range, enabling consistent feature scaling across different survey items. The Risk Level was derived using quantile-based classification at the 33rd and 66th percentiles, ensuring balanced class distribution for model training while maintaining meaningful performance distinctions.
